Statusy raportu: PASS — uruchomiono i przeszło; FAIL — uruchomiono i nie przeszło; BLOCKED — brak emulatora, sekretu lub usługi; NOT RUN — nie uruchomiono. Jeden silnik CAD i jeden model dokumentu obsługują wszystkie modele.  • BYOK: użytkownik podaje własny klucz API dostawcy; opłaty i limity wynikają z jego umowy z dostawcą.  • MCP: standard udostępniania narzędzi aplikacji asystentom AI. MCP nie jest darmowym proxy do subskrypcji ChatGPT ani zamiennikiem API.  • Konta konsumenckie ChatGPT/Claude/Gemini nie gwarantują zewnętrznego dostępu do modeli. Sekrety i bezpieczeństwo  • Klucze API tylko po stronie serwera, szyfrowane envelope encryption/KMS, nigdy localStorage, logi, analityka, repozytorium ani prompt modelu.  • Endpointy użytkownika: blokuj localhost, metadata IP, prywatne adresy i przekierowania do sieci wewnętrznej; wyjątki lokalnego Ollama wyłącznie przez świadomy desktopowy agent lub bezpieczny tunel.  • OAuth 2.1/OIDC dla zewnętrznego MCP, izolacja tenantów, scope per projekt, rate limit, idempotency key, podpisany audyt zmian, zgoda na zapis i możliwość cofnięcia.  • Prompt injection: tekst ze skanu traktować jako niezaufane dane; nie może zmieniać polityk ani wywoływać nieautoryzowanych narzędzi.  6. Analiza zdjęcia → edytowalny CAD  Import PDF/JPG/PNG → korekta perspektywy i obrót → kalibracja wymiarów na co najmniej jednym zweryfikowanym odcinku → rozpoznanie linii, opisów, symboli, skali i warstw → model semantyczny z confidence i source_bbox → walidacja topologii oraz wymiarów → podgląd nałożony na skan → ręczna korekta → zatwierdzenie i zapis. Nie obiecywać automatycznej dokładności 1:1 bez weryfikacji.
